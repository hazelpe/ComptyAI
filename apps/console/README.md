# Console demo

Run `npm run demo` from the repository root with Node.js 22 or newer. No dependency installation, wallet, API key or network access is needed.

The command reads the example epoch and job, budgets a compute pool, allocates credits, executes a mock job and prints the remaining balance. Every run starts with a fresh in-memory ledger. Fixtures and output are explained in [the walkthrough](../../examples/README.md).
