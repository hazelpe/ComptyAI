# Configuration examples

`protocol.example.json` is a design example, not a live configuration or a governance decision. The runnable demo reads its own fixtures in `examples/`; it does not load this file.

Basis points use a denominator of 10,000. The reserve is taken from the treasury share, not from the original gross receipts. Null addresses mean that a deployment has not been recorded. Confirm credit denomination, expiry and eligible balances before implementing a production policy.
