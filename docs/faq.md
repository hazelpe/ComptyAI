# Frequently asked questions

**Is ComptyAI live?** This repository contains project identity, a protocol proposal and a local reference model. It does not record a live token, treasury, compute gateway or funded provider integration.

**What does “free compute” mean?** The proposed treasury pays for a finite allowance, so an eligible holder would not separately pay for compute within that allowance. Gas, capacity limits and service conditions may still apply.

**Does holding a token guarantee unlimited GPUs?** No. Credits depend on collected revenue, confirmed capacity, eligibility and the published epoch policy.

**Are Compute Credits tradable?** The reference design treats them as non-transferable service entitlements. It includes no marketplace or cash redemption.

**Where are the token address and tokenomics?** They are not specified. The repository avoids inventing a ticker, token supply, trading tax, deployment or exchange listing.

**Is Robinhood a partner?** The project targets Robinhood Chain independently. No partnership or endorsement is asserted.

**Which GPUs and providers are supported?** Only a local mock adapter is implemented. Real hardware tiers, providers and service guarantees remain to be selected.

**Can I run this without a wallet?** Yes. `npm run demo` runs entirely locally with fictional inputs and no dependency installation.
