# Glossary

| Term | Definition |
| --- | --- |
| Compute Treasury | The proposed budget and custody layer funding GPU access |
| Compute Credit | A bounded service allowance for a defined tier and epoch |
| Epoch | A published accounting and allocation window |
| Holder snapshot | Eligible balances or weights recorded under an explicit policy |
| GPU tier | A particular hardware and service profile |
| Reservation | Credits held against a job’s maximum authorized usage |
| Settlement | Recording usage and releasing unused reserved credits |
| Basis point | One ten-thousandth of a whole; 100 bps equals 1% |
| Mock provider | A local deterministic simulator with no actual GPU rental |
| Unallocated pool | Funded allowance not assigned to eligible holders |
