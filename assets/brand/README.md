# ComptyAI brand

The original supplied logo is preserved as `logo-original.jpg`. README artwork pairs the logo with a dark green-black canvas, electric lime accents and clear typography.

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#111710` | Dark backgrounds and body text |
| Electric lime | `#D2FF00` | Compute accents and primary emphasis |
| Paper | `#F0F3E8` | Light sections and reversed text |
| Muted sage | `#A5B29F` | Supporting labels on dark backgrounds |

Use the name **ComptyAI** with this capitalization. Approved project phrases: “Turn token activity into compute.”, “Hold tokens. Get compute.” and “We don’t accumulate tokens. We accumulate compute.”

The original image is used without retouching; its native lime tones may vary slightly from the design palette. The banners are code-authored layouts with editable SVG sources and portable PNG exports.
